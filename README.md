# Генератор випадкових рецептів на вечерю

Навчальний проєкт з дисципліни «Програмування веб-застосувань» (2 курс, ФІОТ КПІ).
Варіант 20 — `dinner-recipe-generator`.

## Опис

Клієнтський застосунок, який за запитом користувача пропонує випадковий рецепт
страви на вечерю, показує його інгредієнти та кроки приготування і зберігає
історію згенерованих рецептів.

## Заплановані розділи сторінки

1. Шапка з назвою застосунку.
2. Блок генерації випадкового рецепта.
3. Блок відображення обраного рецепта (інгредієнти, кроки).
4. Блок історії згенерованих рецептів.
5. Підвал.

На цьому етапі (практикум 1) розділи позначені лише коментарями-заглушками
в `body`. Семантичні теги додаються в практикумі 2.

## Як запустити

Відкрити `index.html` у браузері подвійним кліком або через розширення
Live Server у VS Code (правий клік по файлу → «Open with Live Server»).

## Інструменти розробки

- Редактор: Visual Studio Code
- Розширення: Live Server, Prettier
- Браузери для перевірки: Google Chrome, Mozilla Firefox
- Контроль версій: Git + GitHub
